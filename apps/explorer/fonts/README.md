# Fonts

The Explorer serves its three typefaces itself: its content security policy allows fonts from its own
origin only. They are the same files the Playground serves. Each file is the Latin subset of the variable
font (weight axis), taken unchanged from the Fontsource 5.3.0 packages, which repackage the Google Fonts
releases.

| File                         | Family         | Fontsource package                          | Licence |
| ---------------------------- | -------------- | ------------------------------------------- | ------- |
| `space-grotesk-latin.woff2`  | Space Grotesk  | `@fontsource-variable/space-grotesk@5.3.0`  | OFL-1.1 |
| `archivo-latin.woff2`        | Archivo        | `@fontsource-variable/archivo@5.3.0`        | OFL-1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | `@fontsource-variable/jetbrains-mono@5.3.0` | OFL-1.1 |

The SIL Open Font License 1.1 texts, with each family's copyright line, are next to the files and ship with
the pages at `/fonts/OFL-*.txt`, linked from the methodology page.
