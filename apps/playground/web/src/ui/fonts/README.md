# Fonts

The Playground serves its three typefaces itself: the page's content security policy allows fonts
from its own origin only. Each file is the Latin subset of the variable font (weight axis), taken
unchanged from the Fontsource 5.3.0 packages, which repackage the Google Fonts releases.

| File                         | Family         | Fontsource package                          | Licence |
| ---------------------------- | -------------- | ------------------------------------------- | ------- |
| `space-grotesk-latin.woff2`  | Space Grotesk  | `@fontsource-variable/space-grotesk@5.3.0`  | OFL-1.1 |
| `archivo-latin.woff2`        | Archivo        | `@fontsource-variable/archivo@5.3.0`        | OFL-1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | `@fontsource-variable/jetbrains-mono@5.3.0` | OFL-1.1 |

The SIL Open Font License 1.1 texts, with each family's copyright line, are in
[`web/public/fonts`](../../../public/fonts) and ship with the page at `/fonts/OFL-*.txt`.
