---
title: "Deploy a facilitator"
description: "Run the Rail402 facilitator and Bazaar with Docker on stellar:testnet, free and with no API key, in one command."
---

You want to run a facilitator, hosted for others or self-hosted for your own services. This page gets one serving `stellar:testnet` with the Bazaar co-deployed. It is free and open by default, because a facilitator nobody can try is a facilitator nobody adopts.

## Run one

The repository's `Dockerfile` builds the facilitator and Bazaar as one image. The only required setting is the signing account that pays settlement fees.

```bash
docker build -t rail402-facilitator .
docker run -p 8080:8080 \
  -e FACILITATOR_STELLAR_SECRET=S...your-funded-testnet-secret \
  -v rail402-data:/data \
  rail402-facilitator
```

The signing account must be a funded testnet account. Friendbot funds one in [Stellar Lab](https://lab.stellar.org/account/create). The `-v rail402-data:/data` volume keeps the catalog across restarts, because the image sets `CATALOG_DB_PATH=/data/catalog.db`.

To run it from source instead of Docker, on the default port 4022:

```bash
pnpm install
pnpm --filter @rail402.dev/facilitator... build
FACILITATOR_STELLAR_SECRET=S... pnpm --filter @rail402.dev/facilitator start
```

## Verify it

```bash
curl http://localhost:8080/supported
curl http://localhost:8080/health
```

`/supported` lists the `exact` and `upto` schemes on `stellar:testnet` with `areFeesSponsored: true`, and `bazaar` in `extensions`. `/health` reports the networks served, the signer count, and the catalog storage mode:

```json
{ "status": "ok", "networks": ["stellar:testnet"], "signers": 1, "feeBump": "disabled", "catalog": { "entries": 0, "storage": "durable" } }
```

Configuration is validated before the port binds, so a misconfigured deployment fails immediately with a coded, actionable message instead of serving errors to real payments.

## Prove it end to end

Point the conformance canary at your running deployment. It runs a stock client through the whole flow against testnet and exits non-zero if any step fails:

```bash
pnpm canary discovery-loop --facilitator http://localhost:8080
```
