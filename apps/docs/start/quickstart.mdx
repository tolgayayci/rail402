title: "Quickstart"
description: "Run a paid, discoverable x402 payment on stellar:testnet end to end, in one command."
---

The fastest way to see Rail402 work is one command against a Rail402 checkout. It runs the whole loop on `stellar:testnet`: a stock client pays a seller, the facilitator settles on chain, the resource is cataloged, and a natural-language search returns it first.

```bash
pnpm canary discovery-loop --facilitator https://facilitator.rail402.dev
```

It exits non-zero if any step fails and prints the settled transaction hash. From here, pick a path: [Expose a paid API](/seller/quickstart) if you sell, or [Pay for an API](/buyer/quickstart) if you buy.
