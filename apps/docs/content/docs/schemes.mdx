---
title: Schemes
description: exact, and upto — authorize a ceiling, settle actual usage.
---

**`exact`** — the buyer authorizes a precise amount. Specified upstream for Stellar and
supported here on `stellar:testnet`.

**`upto`** — the buyer authorizes a *ceiling* and the server settles actual usage, which is the fit
for metered services. Stellar had no `upto` profile, so this project wrote one and ships a Soroban
contract that enforces the ceiling and single-use on-ledger, rather than trusting the facilitator.
