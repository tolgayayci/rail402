---
title: Error codes
description: One registry. Every rejection carries a code and a non-null reason.
---

Every rejection anywhere in this project carries a machine-readable code **and** a non-null,
human-legible reason. That is enforced by the type system, not by review: `reason` is non-optional,
so a rejection without one does not compile.

Codes are tagged by provenance — `spec`, `library` or `local` — because spec and library codes are a
wire contract we do not own and must reproduce byte-for-byte.
