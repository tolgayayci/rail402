---
title: Facilitator
description: verify, settle, supported — the standard x402 surface for Stellar.
---

The facilitator implements the standard x402 surface — `/verify`, `/settle`, `/supported` —
for Stellar, built on the Apache-2.0 `@x402/stellar` package rather than reimplementing settlement.

It sponsors network fees, so a buyer needs only the payment asset and **no XLM**, and advertises
that truthfully via `extra.areFeesSponsored` — a flag checked nightly against a funded signer.
