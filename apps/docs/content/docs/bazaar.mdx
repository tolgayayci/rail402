`GET /discovery/resources` (offset pagination, key `items`) and `GET /discovery/search`
(cursor pagination, key `resources`). That asymmetry is real and load-bearing — getting it backwards
silently breaks every stock client using `withBazaar()`.

All seven spec filters are implemented and all seven actually filter, which is a low bar the largest
live catalog does not clear.
