title: Conformance
description: How every published number is produced.
---

Acceptance is tested at the wire level, so this project publishes what was **observed**, not
what was intended. Machine-readable reports land in `docs/status/`, and the published tables and
badges are generated from them — CI fails if they drift.

Nightly, against live testnet: the discovery loop, a `/supported` snapshot, a 17-case rejection
audit, onboarding time, and the upstream e2e suite run twice (at our pinned spec SHA and at latest
main, so drift is distinguishable from regression).
