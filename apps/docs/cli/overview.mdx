---

`rail402` is a command-line **x402 wallet for Stellar**. It turns the whole payment loop — *fund →
discover → pay → verify* — into a handful of commands you can run in a terminal or hand to an AI
agent. It speaks the x402 v2 wire format, the buyer needs **no XLM** (the facilitator sponsors fees),
and it defaults to Rail402's hosted testnet infrastructure, which is **free and needs no API key**.

It is the Stellar-native counterpart to the x402 CLIs that already exist for EVM and Solana — the
first one for Stellar.

## Install

```bash
npm install -g @rail402.dev/cli
```

Or run any command without installing:

```bash
npx @rail402.dev/cli <command>
```

<Note>
Every payment requires an explicit `--max` spend cap. The CLI never spends an unbounded amount, and
it is **testnet-only** by construction.
</Note>

## What you can do with it

<CardGroup cols={2}>
  <Card title="Fund a wallet" icon="wallet">
    `rail402 fund` generates a testnet account and funds it via friendbot — no keypair, no faucet, no
    flags.
  </Card>
  <Card title="Discover paid APIs" icon="magnifying-glass">
    `rail402 search "…"` finds paid endpoints and MCP tools in the Bazaar in natural language.
  </Card>
  <Card title="Pay, capped" icon="credit-card">
    `rail402 buy "…" --max 0.10` discovers the cheapest match and pays it; `rail402 pay <url>` pays a
    URL you already have.
  </Card>
  <Card title="Verify on the explorer" icon="receipt">
    `rail402 tx <hash>` looks the settlement up on the Rail402 explorer and prints an openable link.
  </Card>
</CardGroup>

## 60-second tour

<Steps>
  <Step title="Fund a testnet account">
    ```bash
    rail402 fund
    ```
    Save the `S…` secret it prints, then export it:
    ```bash
    export RAIL402_SECRET=S...
    ```
    Friendbot funds XLM. For testnet **USDC**, fund the address at the
    [Circle faucet](https://faucet.circle.com) (select Stellar testnet).
  </Step>
  <Step title="Discover a paid API">
    ```bash
    rail402 search "convert usdc amounts to stroops"
    ```
  </Step>
  <Step title="Discover and pay it — capped">
    ```bash
    rail402 buy "convert usdc amounts to stroops" --max 0.10
    ```
    Amounts are decimals in the asset's units, so `--max 0.10` is 0.10 USDC. The command prints the
    settlement hash and the API's response.
  </Step>
  <Step title="Verify the settlement">
    ```bash
    rail402 tx <hash>
    ```
  </Step>
</Steps>
