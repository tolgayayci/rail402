The Bazaar is a discovery layer over paid services. It turns isolated x402 endpoints into something an agent can shop: sellers declare machine-readable metadata, the facilitator catalogs any resource that carries the discovery extension, and buyers query a catalog and a search endpoint. There is no separate registration step.

It exposes two endpoints, both open GET:

- `GET /discovery/resources` browses the catalog with filters, paginated by offset.
- `GET /discovery/search` ranks the catalog against a natural-language query, paginated by cursor.

The Bazaar catalogs both HTTP endpoints and MCP tools, keeps its index off-chain, and interoperates with the wider x402 discovery ecosystem through the stock SDK types. This section covers its [cataloging lifecycle](/bazaar/cataloging), its [search and ranking](/bazaar/search), and how it stays [tamper-resistant](/bazaar/integrity).
