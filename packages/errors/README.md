# @rail402.dev/errors

Stable error codes for Rail402.

The registry every Rail402 package uses so that each rejection carries a stable, machine-readable `code`, a non-empty `reason` and a `retryable` flag. Codes and their meanings are listed in [Errors and verification rules](https://docs.rail402.dev/verification-rules).

```sh
npm install @rail402.dev/errors
```

Part of [Rail402](https://github.com/tolgayayci/rail402), x402 payments and discovery for Stellar.
Documentation: [docs.rail402.dev](https://docs.rail402.dev). Requires Node.js 24.11 or later. Apache-2.0.
