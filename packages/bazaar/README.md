# @rail402.dev/bazaar

The Rail402 Bazaar catalog for x402 on Stellar.

Catalogs HTTP endpoints and MCP tools from settled x402 payments that carry the `bazaar` extension: schema validation, listings bound to the settled `payTo`, origin verification against the resource's own 402, and a public version history. See [Cataloging](https://docs.rail402.dev/bazaar/cataloging).

```sh
npm install @rail402.dev/bazaar
```

Part of [Rail402](https://github.com/tolgayayci/rail402), x402 payments and discovery for Stellar.
Documentation: [docs.rail402.dev](https://docs.rail402.dev). Requires Node.js 24.11 or later. Apache-2.0.
