Each exercise below provokes one of the threats in the [threat model](/security/threat-model) on purpose and
checks what happens: what is refused, what reaches the chain, what the sponsor pays, and what the service
reports. The exercises are tests in the repository. Most run against a private Stellar network with 1-second
ledgers and the testnet passphrase, where an RPC proxy can hold, drop or inject transactions at a chosen
moment; the public RPC offers no such hook. Where a conformance harness exercises the same behaviour against
the public testnet, its recorded outcome is shown next to the local one.

## Running the exercises

From a [source checkout](/install) with the local services of `docker-compose.yml` running:

```sh
node --conditions=@rail402/source tools/conformance/src/ops.ts
```

`ops.ts` runs every exercise's test files with Vitest, joins each exercise's results with what its tests
recorded (transaction hashes, fees charged, refusal codes), and prints one evidence document with a case per
exercise. `--only balance-race,crash-k0` runs a subset. `--write` records the run in
`tools/conformance/evidence/ops-local-stellar-testnet.json`, only from a clean checkout of `main`, and
`pnpm report` renders the sections below from it. A run in which any exercise could not run (a local
service down, or no Docker for the short-TTL network) exits non-zero and records nothing; `--allow-skips`
records it anyway, with each skipped exercise and its reason, for a rehearsal.

## Recovery drills

Each recovery procedure of the [operator runbook](/runbook#recovery-procedures) is also run as a drill: a
fault is injected into a running service that Prometheus scrapes with the committed alert rules, the alert
is awaited through Alertmanager, the runbook's steps are followed, and the time to detect and to recover is
recorded (`tools/conformance/src/drills-local.ts`, checked by `tools/conformance/src/drills.ts`). Locally
the rules run with their hold times removed, so the detection times measure the signal path, not the
production thresholds.

The local stack also runs the Explorer indexer (its own ingester, store, metrics and health server, over
its own database) for the `degraded-indexing-explorer` drill: its discovery source fails, and the
indexer must catch up by itself once it answers again. Lumeus Activity does not index a private network,
so there discovery reads the network's RPC, and `Rail402ExplorerLag` runs with a 20-second stall window
instead of an hour. The `rpc-failover` drill configures two RPC providers, fails the primary, settles
through the secondary, and waits for the fail-back once the primary returns.
