A public Rail402 instance serves the Stellar testnet. Point any stock x402 seller at it to accept testnet
payments, and read its Bazaar catalog without an account.

```text
{{facilitatorUrl}}
```

| Property   | Value                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------- |
| Network    | `stellar:testnet` only                                                                   |
| Scheme     | `exact` and [`upto`](/facilitator/upto), x402 version 2                                  |
| Assets     | Circle testnet USDC and the [TEST6 test token](/facilitator/assets#the-test6-test-token) |
| USDC       | Contract `CBIELTK6YBZJU5UP2WWQEUCYKLPU6AUNZ2BQ4WWFEIE3USCIHMXQDAMA`, 7 decimals          |
| TEST6      | Contract `CDS45IRSWVDBV4JM2FPZ52EYXYO54J6DJL35GOSXOTRA4BYM6FFRK2BK`, 6 decimals          |
| Fees       | Sponsored: `extra.areFeesSponsored` is `true`; the payer pays no network fee             |
| Access     | Free, no API key                                                                         |
| Extensions | `bazaar`                                                                                 |

It runs the repository's [Docker image](/facilitator/docker) with Postgres, behind a reverse proxy, and
`/health` reports the version it was deployed with (`RAIL402_VERSION`). It does not serve `stellar:pubnet`.

## Pay through it

The quickest end-to-end check is the canonical client run from a [source checkout](/install). It creates and
funds a fresh buyer and seller with Friendbot, buys testnet USDC for the buyer, starts a stock
`@x402/express` seller on `127.0.0.1` that uses the hosted facilitator, and pays it with stock `@x402/fetch`.
`--payer g` keeps the run to the stock client alone; by default it also pays from a smart account (C…),
which Rail402's test client signs because the stock client signs for G… accounts only:

```sh
node --conditions=@rail402/source tools/conformance/src/canonical.ts --facilitator {{facilitatorUrl}} --payer g
```

It prints one evidence document: each payment's settlement transaction with its Stellar Expert link, the
fee, the transfer read back from the chain and the bytes the seller forwarded, and it exits non-zero unless
every settlement succeeded on-chain with the payer debited and the seller credited the amount. Recorded runs
are on the [Conformance evidence](/reference/conformance) page: the runs recorded against a local Rail402 at
the tested commit, and a run against this service once one is recorded after its latest deployment.

To build your own, follow the [buyer](/quickstart/buyers) and [seller](/quickstart/sellers) quickstarts.

## Limits

- **Rate limits.** Requests are limited per client address. The reverse proxy in front of the instance sets
  `X-Forwarded-For` to the client's address, and the instance trusts that one hop (`TRUSTED_PROXY_HOPS=1`), so
  the limit counts the client, not the proxy. A limited request gets HTTP `429` with a `Retry-After` header
  and the code `rate_limited`.
- **Operator policy.** The accepted assets, amount bounds, `maxTimeoutSeconds` range and settlement fee
  ceilings are configuration; the defaults are on the [Configuration](/configuration#per-network) page. A
  payment outside them is refused with a specific code: `invalid_exact_stellar_requirements_*` or
  `invalid_exact_stellar_payload_fee_exceeds_maximum` for `exact`, and `invalid_upto_stellar_requirements_*`
  or `invalid_upto_stellar_payload_fee_exceeds_maximum` for `upto`. Amounts are SEP-41 base units:
  `10000000` is 1 USDC, `1000000` is 1 TEST6.
- **Cataloging.** Only resources on public hosts are cataloged. A seller on `localhost` or a private address is
  paid normally, but its listing is refused with `bazaar_resource_unsafe`.
- **Testnet only.** Testnet accounts, balances and the catalog carry no value.

## Discovery

The catalog is public:

```sh
curl "{{facilitatorUrl}}/discovery/resources?limit=5"
curl "{{facilitatorUrl}}/discovery/search?query=weather%20data%20under%201%20cent"
```

The hosted catalog lists the resources of the public demo seller (`apps/demo-seller`, at
`https://demo.rail402.dev`), paid through this facilitator, with their payment options,
bazaar metadata, trust and Stellar facts.

See [Discovery API](/bazaar/discovery) and [Search](/bazaar/search).
